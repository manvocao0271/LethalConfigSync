# Changelog

## [0.0.2] - 2026-10-09 (BETA)

- added `SyncHeadBobbing`: host-only option that applies the host's in-game head bobbing setting to players. It isn't saved to their game, and their own value comes back when they leave. This changes the protocol version, so everyone must update together.
